# Petroleum Lecture - Веб-сайт на GitHub Pages

🌐 **Минималистичный образовательный сайт** о нефтегазовой промышленности с двуязычным контентом (англ./рус.)

## 📋 Описание проекта

Сайт предназначен для изучения основ нефтегазовой промышленности через:
- 📖 **Текст лекции** на английском и русском языках
- 📚 **Интерактивный словарь** с возможностью поиска
- 🎨 **Минималистичный дизайн** с плавными формами
- 🌙 **Светлая и темная темы**
- 📱 **Адаптивный дизайн** (мобильные устройства)

## 🏗️ Структура проекта

```
Petrolium-lecture/
├── index.html              # Главная страница
├── lecture.html            # Страница с текстом лекции
├── dictionary.html         # Страница со словарем
├── css/
│   └── style.css          # Единые стили (светлая/темная тема)
├── js/
│   ├── theme-switcher.js  # Переключение темы
│   ├── lecture-loader.js  # Загрузка и переключение языков
│   └── dictionary-pyscript-handler.js  # Обработка поиска
├── data/
│   ├── dictionary.json    # Словарь терминов с переводами
│   └── lectures.json      # Тексты лекций (EN/RU)
└── README.md              # Этот файл
```

## 🔍 PyScript интеграция

> **МЕСТО ДЛЯ PYTHON ЛОГИКИ ПОИСКА**

Проект готов к интеграции PyScript для расширенной логики поиска. В файле `dictionary.html` уже подготовлены места для добавления Python кода:

```html
<!-- PyScript загружается здесь -->
<script defer src="https://pyscript.net/latest/pyscript.js"></script>
<py-config>
    packages = ["regex"]
</py-config>
```

Вы можете добавить Python код для:
- Регулярных выражений в поиске
- Более сложной фильтрации
- Анализа текста

## 🌙 Темная/светлая тема

Переключение темы выполняется через кнопку в заголовке (🌙/☀️). Выбор сохраняется в `localStorage`.

### Как работает:
1. Нажимаем на кнопку в заголовке
2. Класс `dark-theme` добавляется/удаляется из `<body>`
3. CSS переменные автоматически меняются
4. Выбор сохраняется

## 🔧 Как редактировать содержимое

### Изменить текст лекции:
1. Откройте `data/lectures.json`
2. Замените текст в полях `en` и `ru`
3. HTML теги поддерживаются

### Добавить слова в словарь:
1. Откройте `data/dictionary.json`
2. Добавьте объект в массив `words`:
```json
{
  "id": 16,
  "english": "your word",
  "russian": "ваше слово",
  "category": "resources"
}
```

### Добавить внешнюю ссылку:
1. Откройте `index.html`
2. Найдите элемент с `id="external-link"`
3. Замените `href="#"` на вашу ссылку
4. Удалите атрибуты `style` для активации
